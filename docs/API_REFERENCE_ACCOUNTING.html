GET Batches
ดึงข้อมูล Batch ระดับต่างๆ — ตั้งแต่ list ธรรมดาจนถึง full relation
GET
/Batches
ดึง batch ทั้งหมด (ไม่มี nested data)
›
GET/Batches
GET/Batches?$top=20&$orderby=billDate desc
GET/Batches?$filter=hisDocumentType eq 'RECEIPT_OPD' and billDate eq 2026-09-15
OData Query Options ที่ใช้บ่อย
Parameterตัวอย่างคำอธิบาย
$top$top=10จำกัดจำนวน record
$skip$skip=20ข้าม N records (pagination)
$orderby$orderby=billDate descเรียงลำดับ
$filter$filter=currency eq 'THB'กรองข้อมูล
$select$select=ID,billDate,currencyเลือกเฉพาะบาง field
$count=true$count=trueนับจำนวนทั้งหมด
GET
/Batches(guid'<ID>')

›
GET/Batches(guid'8dc208b4-a592-442d-8cdc-5d791acb88b9')
GET/Batches?$filter=ID eq 8dc208b4-a592-442d-8cdc-5d791acb88b9

GET Items

GET
/Items
ดึง items ทั้งหมด
›
GET/Items
GET/Items?$filter=batch_ID eq 8dc208b4-a592-442d-8cdc-5d791acb88b9
GET/Items?$filter=billingGroup eq 'DEFAULT' and netAmount gt 100
GET/Items?$filter=fiPosting_ID eq null ← items ที่ยังไม่ post FI
GET/Items?$select=itemCode,itemName,netAmount,billingGroup&$orderby=itemNumber
