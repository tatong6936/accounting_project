One-time Setup ทำครั้งเดียว

ทำครั้งแรกเท่านั้น ไม่ต้องทำซ้ำในแต่ละครั้งที่ test

cf login -a https://api.cf.ap11.hana.ondemand.com
cf enable-ssh accounting-srv
cf restart accounting-srv
⚠️ ไฟล์ที่ต้องมีก่อน test (อย่า commit ไป git!)
  • accounting/.cdsrc-private.json — DB credentials ผ่าน SSH tunnel
  • accounting/.env — VCAP_SERVICES สำหรับ Destination service (S/4HANA SOAP)
ดูเนื้อหาไฟล์ที่ส่วน "Key Files" ด้านล่าง
▶

ทุกครั้งที่ต้องการ Test ทุก session

ต้องทำทั้ง 2 terminal พร้อมกัน (เปิด Terminal 1 ก่อน รอให้ tunnel พร้อม แล้วค่อยเปิด Terminal 2)

Terminal 1 — SSH Tunnel 
cf ssh accounting-srv \
  -L 15432:postgres-5c194fbb-6c66-47b4-aaa0-80860eccf804.capm0ncdfykh.ap-southeast-1.rds.amazonaws.com:5887

เปิดทิ้งไว้ตลอด ไม่ต้องปิด — หยุด tunnel = cds serve หยุดเชื่อม DB

Terminal 2 — CAP Server 
cd accounting
cds serve --profile hybrid

เมื่อ log ขึ้น "serving CdsService..." แสดงว่าพร้อมแล้ว

วิธีทดสอบ

ดู Batches ทั้งหมด

GET http://localhost:4004/odata/v4/accounting/Batches

เรียก postFI — แบบที่ 1: ส่ง batchId (1 batch)

POST http://localhost:4004/odata/v4/accounting/postFI
Content-Type: application/json

{
  "batchId": "<ใส่ batchId จริงจาก DB>"
}

เรียก postFI — แบบที่ 2: ส่ง hisDocumentType + billDate (หลาย batch)

POST http://localhost:4004/odata/v4/accounting/postFI
Content-Type: application/json

{
  "hisDocumentType": "RECEIPT_OPD",
  "billDate": "2025-06-01"
}
📦 Package Size ระบบจะดึง batch มาทำทีละ 100 รายการ วนจนกว่าจะหมด (เหมือน ABAP SELECT ... PACKAGE SIZE 100)
ถ้าต้องการเปลี่ยนขนาด แก้ที่ accounting/srv/accounting-service.js บรรทัด const PACKAGE_SIZE = 100

ค่า hisDocumentType ที่ใช้ได้

INVOICE_OPD · INVOICE_IPD_INTERIM · INVOICE_IPD_FINAL
RECEIPT_OPD · RECEIPT_IPD_INTERIM · RECEIPT_IPD_FINAL
ONWARD · CREDIT_NOTE · DEBIT_NOTE · DEPOSIT · REFUND_DEPOSIT
✅ ผลสำเร็จ "postFI done — processed: 3, skipped: 0, failed: 0, FI docs: 3"
❌ ถ้า error — เช็ค:
  • Terminal 1 ยังเปิดอยู่ไหม? (SSH tunnel)
  • ไฟล์ .env และ .cdsrc-private.json มีอยู่ไหม?
  • ใช้ Network บ้าน/Hotspot อยู่ไหม? (ไม่ใช่ VPN corporate)
  • Error message จะบันทึกลง JournalEntryMessages (msgType = E) และ JournalEntryStatus = ERROR

สรุป Architecture ของ Local Testing

localhost:4004 (cds serve)
   │
   ├── DB queries ──→ localhost:15432 (SSH tunnel port)
   │                        │
   │                        └──→ CF container ──→ BTP PostgreSQL (AWS RDS ap-southeast-1) :5887
   │
   └── SOAP call ──→ S/4HANA (via Destination service)
          │
          ├── อ่าน credentials จาก VCAP_SERVICES (.env)
          ├── ขอ token จาก UAA
          ├── ดึง destination config (S4H_SOAP_DEST)
          └── POST SOAP → JournalEntryCreateRequest → FI Document ✅
